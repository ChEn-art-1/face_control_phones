# FaceControl - Android 面部手势辅助工具 🚀

中文版 | [English](./README.md)

**FaceControl** 是一款开源的 Android 应用，利用计算机视觉技术，让用户仅通过面部动作（眨眼、抬头/低头、扭头、张嘴）即可对手机进行全局控制。

该项目旨在为残障人士提供全新的交互方式，或在不方便手动操作（如洗手、下厨）时实现免触摸的手机操作。

---

## ✨ 核心特性

- **实时面部追踪**：基于 **Google MediaPipe Face Landmarker**，实时检测 468 个面部 3D 关键点。
- **后台持续监听**：结合 **CameraX** 与 **Foreground Service**（前台服务），即使 App 退到后台或屏幕锁定，依然能持续响应。
- **全局手势模拟**：利用 **Accessibility Service**（无障碍服务），无需 Root 权限即可在任意应用中模拟滑动、点击和长按。
- **准心模式（自选点击位置）**：双击眨眼进入准心模式，偏头移动光标，自由指定点击与长按的落点，并自动识别光标附近的可交互元素并高亮。
- **智能点击识别**：点击与长按优先命中光标正下方的实际可点击控件，找不到时才回退到原始坐标手势。
- **防误触逻辑**：内置 EAR（眼径比）状态机与自适应基线，区分生理眨眼与控制指令。

## 🛠️ 技术栈

- **语言**：Kotlin
- **UI 框架**：Jetpack Compose
- **视觉计算**：[MediaPipe Tasks Vision](https://developers.google.com/mediapipe)
- **相机支持**：CameraX（Camera2）
- **系统接口**：Android Accessibility Service API
- **后台架构**：Lifecycle-aware Foreground Service

## 📸 动作映射表

### 竖屏模式（刷短视频 / 翻页浏览）

| 面部动作 | 模拟手势 | 典型场景 |
| :--- | :--- | :--- |
| **低头** | 向下滑动 | 向下翻页、刷新 |
| **抬头** | 向上滑动 | 向上翻页、下一条 |
| **左扭头** | 向左滑动 | 返回、上一项 |
| **右扭头** | 向右滑动 | 前进、下一项 |
| **长闭眼**（约 0.8 秒） | 在选定位置点击 | 确认、选中、暂停 |
| **张嘴** | 在选定位置长按 | 长按菜单、倍速播放 |
| **闭嘴** | 松手 | 结束长按 |
| **双击眨眼** | 切换准心模式 | 进入 / 退出准心模式 |

### 横屏模式（看电影 / 全屏视频）

| 面部动作 | 模拟手势 | 典型场景 |
| :--- | :--- | :--- |
| **低头** | 向下滑动 | 音量 / 亮度降低 |
| **抬头** | 向上滑动 | 音量 / 亮度提高 |
| **长闭眼**（约 0.8 秒） | 在选定位置点击 | 播放 / 暂停 |
| **张嘴** | 在选定位置长按 | 播放器菜单 / 倍速 |
| **闭嘴** | 松手 | 结束长按 |
| **双击眨眼** | 切换准心模式 | 进入 / 退出准心模式 |

> 横屏模式下暂未映射摇头手势。

## 🎯 准心模式

双击眨眼进入准心模式，屏幕上出现十字光标，通过上下左右偏头来控制光标移动方向：

- 头部回到中立位置时，光标停止移动。
- **绿色框** = 点击（长闭眼）实际会命中的位置。
- **橙色框** = 长按（张嘴）实际会命中的位置。

高亮框会框住光标正下方识别到的真实可交互控件，让你清楚地看到「会点哪里、会按哪里」。再次双击眨眼即可确认位置并退出。之后，点击和长按操作都会使用你选定的位置（若从未选定，则默认屏幕中心）。

## 🚀 快速开始

### 环境要求

- Android 8.0+（API 26+）
- 建议使用真机测试（模拟器摄像头支持有限）

### 1. 编译运行

使用 Android Studio 打开项目，Sync Gradle，然后运行。

### 2. 授予权限

安装后，请在系统设置中手动开启以下权限：

1. **相机权限** — 用于实时捕捉面部画面
2. **悬浮窗权限**（显示在其他应用上层）— 用于显示准心悬浮窗
3. **无障碍权限** — 在「无障碍 / 辅助功能」设置中找到「FaceControl Service」并开启，App 才能模拟全局手势并识别可交互控件

> ⚠️ 修改无障碍服务配置后，可能需要将该服务关闭再重新开启（或重装 App）才能让新配置生效。

### 3. 开始使用

- 点击「START FACECONTROL」启动摄像头与手势检测
- 通知栏显示「FaceControl is active」表示服务运行中
- 双击眨眼进入准心模式，偏头移动光标定位，再次双击眨眼确认

## ⚙️ 面部动作检测算法

### 眨眼检测

利用每只眼睛 6 个关键点计算 EAR（眼径比），当 EAR 低于自适应基线的某个比例时判定为闭眼。根据闭眼时长区分动作类型：

- **< 300ms** → 生理性眨眼（参与双击眨眼判定）
- **300–800ms** → 忽略（防误触区间）
- **≥ 800ms** → 主动长闭眼（点击）

双击眨眼为两次短眨眼，间隔约 80–700ms。

### 偏头方向

利用鼻子位置在面部宽度（水平）与面部高度（垂直）中的比例判断偏头方向。准心模式下使用更窄的死区，较小的偏头幅度即可移动光标。

### 张嘴 / 闭嘴

利用上下唇距离与嘴巴宽度的比值（MAR）判断，超过阈值即判定为张嘴。
